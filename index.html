Selected Projects

Clinical machine learning

Differential Diagnosis in Hematology

Built and evaluated machine-learning models for differential diagnosis across ten groups of hematological diseases using longitudinal clinical and laboratory records. The project included dataset construction, missing-data handling, feature selection, testing on independent patient data, and analysis of diagnostic errors. The work became the basis of my master’s thesis and first-author publication.

Python · pandas · scikit-learn · model validation · clinical data
Clinical information systems

Clinical Knowledge Retrieval

Developing an internal system for searching and working with clinical and research documents. The prototype combines document indexing, semantic retrieval, structured information extraction, and responses linked to source materials. It is designed for deployment within a protected medical infrastructure where sensitive data cannot be transferred to external cloud services.

Python · Qdrant · local LLMs · document retrieval
